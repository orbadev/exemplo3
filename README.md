# caktus — landing page

landing page institucional desenvolvida para a caktus, empresa de tecnologia.

## sobre o projeto

página única com foco em conversão, apresentando os serviços da empresa e direcionando o visitante para o contato. sem excesso de informação, sem distrações.

## o que foi entregue

- design responsivo (mobile e desktop)
- seções: hero, serviços, sobre, contato
- formulário de contato integrado
- seo básico configurado
- hospedagem inclusa no plano mensal

## tecnologias

- html, css, javascript
- hospedagem via servidor dedicado
- domínio configurado pelo cliente

## prazo de entrega

7 dias úteis após aprovação do briefing.
